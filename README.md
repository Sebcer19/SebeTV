# Sébé TV

Prototype gratuit d’accueil Android TV : trois ambiances, applications installées et favoris.

[Télécharger Sébé TV 0.1 (APK)](https://github.com/Sebcer19/SebeTV/raw/refs/heads/main/SebeTV.apk)

## Installation

Ouvrir le lien APK dans Downloader sur la télévision, puis lancer l’installation. Si nécessaire, autoriser cette source dans les paramètres Android. Ouvrir ensuite Sébé TV depuis les applications.

Android 8 ou supérieur. APK de développement signé, compilé et analysé avec Android Lint (0 erreur, 9 avertissements). Pas encore testé sur une télévision physique. Cette version ne remplace pas automatiquement l’accueil Google TV : commencer par un essai comme application classique.
